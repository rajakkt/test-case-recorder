Smart Script — Install Guide

Smart Script is a Chrome/Edge extension that records browser actions, uploads test cases to Zephyr using your browser session, and exports them as Word, Excel, or PDF documents.

Install on Google Chrome

  1. Unzip the shared SmartScript-v5.zip to a permanent folder (for example Documents\SmartScript). Chrome loads the extension from this location, so do not delete or move it afterwards.
  2. Open chrome://extensions.
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked.
  5. Select the unzipped folder (the one that contains manifest.json).
  6. The Smart Script icon (green lightning bolt) appears in the toolbar. Pin it via the puzzle-piece menu for quick access.

Install on Microsoft Edge (same extension)

  1. Unzip to a permanent folder.
  2. Open edge://extensions.
  3. Enable Developer mode (left sidebar).
  4. Click Load unpacked and select the folder.

Using it

  • Keep a Zephyr tab open and signed in (required for uploads).
  • Record your flow, then enter a Title (and optional Folder path).
  • Click Upload to Zephyr, or use Export to save as Word (.docx), Excel (.xlsx), or PDF.

Notes

  • Keep the folder where it was unzipped; deleting it removes the extension.
  • Updates: replace the folder contents with the new version, then click the reload (↻) icon on the extension card at chrome://extensions.
  • Chrome may show "Disable developer mode extensions" on startup — this is expected for unpacked extensions; click Keep.
  • Works on Chrome and Edge (Windows and macOS).
Tip: The Zephyr session token is short-lived (~15 minutes). If an upload fails with a session/expired message, refresh the Zephyr tab and try again.
